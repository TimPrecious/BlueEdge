        Help & guide

        Everything you need to use and look after this tool.

        Quick start

        1

        Create a task

        Click New task. Type a title, then pick a priority and a due date if you want.

        2

        Work through it

        Use the search box, filters and sort menu to find what matters today.

        3

        Finish it

        Click the round button on a task to mark it complete. You will see a confirmation first.

        Feature guide

        Adding a task

        Click New task (or press N). A window opens.

        • Title is required (up to 100 characters).
        • Description is optional. Use it for extra details.
        • Due date is optional. The Today, Tomorrow and In 1 week buttons are shortcuts.
        • Priority can be Low, Medium or High.
        Completing a task

        Click the round button on the left of a task. A window asks "Are you sure you want to continue?". Click Confirm and the task is marked complete, with the date and time saved.

        Important: completed tasks are final. They cannot be edited or reopened. You can still delete them.

        Editing and deleting

        Use the pencil button to edit an active task. Use the bin button to delete a task. Deleting always asks you to confirm, and it cannot be undone.

        Search, sort and filter
        • Search looks in titles and descriptions. Press / to jump to it.
        • Sort by newest, oldest, due date or priority.
        • Filters show All, Active or Completed tasks. The numbers show how many are in each group.
        • Clear completed removes all finished tasks at once (after you confirm).
        Dates and overdue tasks

        Each task shows when it was created, when it is due and, once finished, when it was completed. If a due date has passed and the task is still active, it is marked Overdue in orange.

        The Dashboard

        The Dashboard tab shows totals, your completion rate, active tasks by priority, tasks that need attention soon, and your most recently completed tasks.

        For administrators

        How the tool is built

        It is made of three files kept together in one folder: index.html (the page), style.css (the look) and script.js (how it works). There is nothing to install and no server. Open index.html in a browser to run it.

        Changing colours

        Open style.css. The colour lists at the top (:root for light mode and [data-theme="dark"] for dark mode) control every colour in the tool. Change a value there and save.

        Adding a new field to tasks

        For example, "Assigned to". Four small changes are needed:

        1. Add an input to the task form in index.html.
        2. In script.js, read the new input when a task is saved (search for saveTaskFromForm).
        3. Keep the field when saved data is loaded (search for sanitizeTasks).
        4. Show it on the card (search for createTaskItem).
        <<<<<<< HEAD About the demo login

        This login is a prototype. Accounts and passwords are stored in the browser (passwords are scrambled, not saved as plain text), and there is no server. That means it is not secure against someone with access to the computer, and accounts cannot be shared between devices.

        For real use, the login needs an online service that stores accounts and tasks safely. The screens and features here can be reused for that.

        ======= >>>>>>> 64f4c01c384b7bed15a80ba21f709f04ffb2d1b3 Making a safe copy before editing

        Copy the whole folder first. If something breaks, delete the edited folder and use the copy again. Tasks are stored in the browser, so they are not affected by file changes.

        Common questions

        Why can't I edit a completed task?

        Completed tasks are locked so the record of finished work stays accurate. If a task was completed by mistake, delete it and create it again.

        My team can't see my tasks. Why?

        This tool saves tasks in each person's own browser. It does not send data anywhere, which keeps it simple and private, but it also means tasks are not shared. Use Download backup and Restore from backup to move tasks to another computer.
