# BrightEdge Task Manager

Double-click `index.html` to open the tool in any modern browser. Keep `index.html`, `style.css` and `script.js` together in the same folder.

The full documentation is built into the tool. Open the **Help** tab (or press `?`) for the user guide, keyboard shortcuts, backup and restore, and notes for administrators. A short welcome tour appears on the first visit and can be replayed from the Help tab."# BlueEdge"
