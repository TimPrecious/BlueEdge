# BrightEdge Task Manager

Double-click `index.html` to open the tool in any modern browser. Keep `index.html`, `style.css` and `script.js` together in the same folder.

The first screen is a **demo login**. Create an account, then log in. Accounts and tasks are saved only in this browser, so this is a prototype and not real security. Please do not use a real password.

The full documentation is built into the tool. Open the **Help** tab (or press `?`) for the user guide, keyboard shortcuts, backup and restore, and notes for administrators. A short welcome tour appears the first time each account signs in and can be replayed from the Help tab.
